## 2. Real-World Context & Detailed Scenarios

To translate the lecture discussion into actionable investor understanding, consider the following practical scenarios and industry mechanics:

- TRI vs PRI Distortion Example: Over 10 years, Nifty 50 Price Index generated ~12% CAGR, but Nifty 50 Total Return Index (TRI) generated ~13.5% CAGR due to reinvested dividend yields. Pre-2018, an active fund delivering 13% claimed '1% Alpha' against PRI, while it was actually underperforming the true TRI benchmark by 0.5%.
- Core and Satellite Portfolio Architecture: Allocating 60-70% of equity capital to 'Core' assets (Nifty 50 Index Fund / Flexi Cap Fund) and 30-40% to 'Satellite' assets (Mid Cap, Small Cap, or Sectoral/Thematic allocations).

---

## 3. Practical Investor Takeaways

1. Always verify active fund performance against Total Return Index (TRI) benchmarks.
2. Use a Core-and-Satellite framework to balance long-term stability with tactical alpha generation.
